# Instruções para Executar o BOT-INFORTECH

## 1. Acessar a pasta principal

Vá até a pasta `Certsempre Automacao` que está na Área de Trabalho.

## 2. Abrir subpasta do projeto

Dentro dela, abra a pasta `BOT-INFORTECH`.

## 3. Abrir com Visual Studio Code

Clique com o botão direito em qualquer área **vazia** dentro da pasta e selecione **"Abrir com Visual Studio Code"**.

## 4. Abrir o script principal

No VS Code, vá até a pasta `desktop` e clique no arquivo `app.py`.

## 5. Executar o aplicativo

No canto superior direito da janela do VS Code, clique no botão de execução (ícone de play ▶️).

## 6. Preencher os dados da interface

A janela que abrirá pedirá três informações:

- **Caminho:**  
  `C:\Users\Pessoal\Desktop\Certsempre Automacao\BOT-INFORTECH\Clientes Infortech TEF.xlsx`

- **Página:**  
  `Clientes sem falha`

- **Quantidade de notas:**  
  Como o código usa um `for` para iterar, insira a **quantidade de notas desejadas - 1**.

## 7. Enviar

Clique no botão **"Enviar"** para iniciar o processo.
